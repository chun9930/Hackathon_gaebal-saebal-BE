# BE_MCM

## 서비스 소개

MCM Private Circle은 매장 방문 고객의 이력과 관심 정보를 누적해서, 고객이 다시 방문했을 때 CA(Client Advisor)가 이전 맥락을 빠르게 파악하고 더 정확하게 응대할 수 있도록 돕는 서비스입니다.

핵심은 "고객 재방문 시 이전 기록을 잃지 않고, 짧은 시간 안에 맞춤형 응대를 가능하게 하는 것"입니다.

## 주요 기능

### 고객 기능
- 회원가입 / 로그인
- 내 프로필 조회 및 수정
- 내 관심 상품 저장 및 조회
- 내 스탬프 조회
- QR 기반 고객 식별

### CA(Client Advisor) 기능
- 직원 로그인
- 고객 조회 및 QR 조회
- 방문 생성 및 방문 기록 작성
- 고객 관심 상품 기록
- 구매 이력 기록
- 방문 스탬프 발급
- 최신 고객 정보 확인
- AI 브리프 조회

### AI 브리프 기능
- 고객의 이전 방문 기록, 관심 상품, 구매 이력을 바탕으로 요약 브리프 생성
- 방문 목적, 관심 포인트, 응대 시 주의사항, 추천 응대 방향 제공
- 실시간 채팅이 아니라 재방문 응대를 돕는 요약형 기능에 집중

## 서비스 흐름

1. 고객 또는 직원이 로그인합니다.
2. 고객은 계정 또는 QR로 식별됩니다.
3. 고객이 매장에 방문하면 방문 이력이 생성됩니다.
4. CA가 방문 후 메모, 반응, 주의사항 등을 기록합니다.
5. 관심 상품, 구매 이력, 스탬프가 누적됩니다.
6. 고객이 다시 방문하면 AI 브리프를 통해 과거 맥락을 빠르게 확인합니다.

## 기술 스택

- Backend: Spring Boot, Spring Security, JWT, JPA, MySQL
- Frontend/Mobile: Expo / React Native 기반 앱 소스 포함
- AI: Google Gemini API
- Infra: GitHub 기반 협업, 클라우드 배포 가능 구조

## 저장소 구성

- `src/`: Spring Boot 백엔드 코드
- `HackaThon/mobile/`: 모바일 앱 코드
- `src/test/`: 인증, 회원가입, 회귀 테스트 포함

## 현재 반영 포인트

- 고객 회원가입/로그인 및 직원 로그인 분리
- 고객 검색 입력 검증 및 오류 처리 개선
- QR 식별 및 고객 조회 흐름 정리
- 로그인/회원가입 관련 회귀 테스트 보강
- PEM 키 및 환경파일이 저장소에 올라가지 않도록 ignore 규칙 추가
